How It Works

1. Right-Click

Control-click in any Finder window or on the desktop. Select New File Menu from the context menu.

2. Choose Template

Pick from 30+ built-in options or your customs. The right extension is added automatically.

3. File Created

A confirmation sound plays. The new file appears, revealed in Finder—ready to edit.

4. Customize Further

Open automatically if preferred. Tweak templates and options in Preferences for your ideal setup.

 

FAQ

Is this the full version?

Yes, this is the fully activated version of New File Menu 1.8.6—no purchases or activations needed.

How do I enable templates?

Open Preferences from the menu bar. Toggle built-ins on or off, and add customs via the Templates tab.

Does it work on desktop?

Absolutely. Right-click anywhere in Finder, including desktop, for instant file creation.

Can I use keyboard shortcuts?

Yes, in 1.8.6: Preferences > General > Show actions to assign and trigger via shortcut.

What macOS versions are supported?

Optimized for modern macOS, including Sonoma and Sequoia. Runs smoothly on Apple Silicon and Intel.
